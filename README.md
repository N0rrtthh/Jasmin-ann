# Kilalanin si Jasmin 🚒

Recite-along self-introduction for OJT at BFP Alfonso Fire Station.

## Put it online (GitHub Pages)
1. Upload everything in this folder to the repo root (`index.html` must be at the top level).
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
3. After ~1 minute the site is live at: https://n0rrtthh.github.io/Jasmin-ann/

## Admin
- Tap **🔒 Admin** at the bottom of the home screen. Default password: `bfpalfonso2026` (change it inside Admin, then Publish).
- New/edited details show on your phone right away. To show them on everyone's phone, tap **Publish** (needs a GitHub fine-grained token with *Contents: Read and write* on this repo only — steps are shown in Admin), or **Download data.json** and upload it to the repo.

## Files
- `index.html`, `styles.css`, `app.js` — the site
- `data.json` — your details (this is what Publish updates)
- `assets/jasmin.jpg` — photo
